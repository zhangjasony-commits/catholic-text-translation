# 中文使用示例

先安装完整技能，并提供实际可读取的原文或文件。以下提示词使用 Codex 的 `$catholic-text-translation` 调用形式；支持技能选择器的客户端可以先选择技能，再输入同样的任务内容。

提示词中的【方括号】是需要替换的内容。它们是任务示例，不是已经完成的翻译或测评。

## 1. 短篇原文翻译

```text
请使用 $catholic-text-translation，把以下原文翻译为简体中文。

材料：【粘贴原文，包含必要邻文】
作者与作品：【已知信息；不知道的注明未知】
范围：【全文或具体章节、段落】

请保留标题、条号及注释关系，使用适合作者和时代的天主教术语。
先检查主体、对象、条件、否定和指代，再通读中文并回查改动。
正文只给中文；关键歧义放简短译注，未解决的局部问题明确说明。
注明直接翻译或转译，以及非官方中文自译身份。
```

交付重点：中文译文、必要译注、底本与局部未解项。

## 2. 经院哲学或神学论证

```text
请使用 $catholic-text-translation，翻译这段经院哲学／神学文本。

原文：【提供实际文本及必要邻段】
作者、作品和定位：【可核实的信息】
已有术语约定：【如有，请提供】

请先辨明哪些是作者解答、异议、引述或答复，保留各层次。
对 essentia、esse、actus、potentia、natura 等术语按本段语境决定译法；
不要将后世某一学派的解释补入正文。
保留论证前提、推理连接、条件与否定，中文可以拆句，但不能缩成摘要。
只在影响理解时保留短原词，解释性补充标为译注。
```

交付重点：论证完整的中文译文、关键术语说明及未决解释。

## 3. 公会议文件与草案比较

```text
请使用 $catholic-text-translation，整理并翻译我提供的几份会议材料。

文件：【提供文件】
纳入范围：【哪些正文、附录和注释要译】

先检查实际题名、语言、章条范围与文本身份。
分清最终文本、草案、不同修订阶段、编者附录及参考译本。
有依据的完全重复只译一次并保留指向；不同见证或修订文字不要当作冗余删除。
列出缺页和独有内容；只用可靠见证补缺，并注明来源和定位。
按所选范围生成中文译稿，目录和分部标题要能辨明各类文本。
```

交付重点：最少必要的文件与版本说明、译稿、补缺及未解项。

## 4. 已有译稿复校

```text
请使用 $catholic-text-translation，逐单元核对以下原文与中文译稿。

原文：【提供原文、定位及必要上下文】
译稿：【提供当前译稿】
复核范围：【明确章节或段落】

优先检查漏译、增义、修饰关系、指代、条件和否定，以及关键术语。
分开列出：确证含义误译、可接受异译、表达改善、来源问题和待核验项。
每个实质问题给出定位、改前、改后和简短依据。
修改整句及必要邻段，检查同类结构，并同步相关译注。
完成后通读中文，再回查改变意义关系的所有改动。
只报告实际复核过的范围。
```

交付重点：校订稿、有依据的修正记录，及未完成的复核范围。

## 5. 圣经引文专项核验

```text
请使用 $catholic-text-translation，核对这份文献及译稿中的圣经引用。

文献原文与原注：【提供文本】
当前译稿：【如有，请提供】
中文参照：思高译本【或指定其他版本】

按实际引语核定书名、经节、直接引文／节引／意译／典故和引用边界。
只译文献实际引用的内容，不补成完整经节。
若所引原语版本与中文参照存在实质差异，按所引文字处理并说明。
读取不到参照正文或无法确认编号对应时，保留待核验状态。
交付修订后的引文和最少必要的逐项核验说明。
```

交付重点：经文处理结果、版本及范围差异、局部未核验项。

## 6. 长篇翻译与续接

```text
请使用 $catholic-text-translation，分批翻译这部长篇文献。

底本：【文件或可读取链接】
范围：【明确所译部分】
输出：【简体／繁体、中文单语或对照、文件格式】
每批规模：【一个完整章节或若干完整论证段落】
已有材料：【术语表、已译稿、项目状态；如没有注明没有】

保存底本选择、项目术语、覆盖记录和最后完成位置。
每批保留必要邻文，检查跨段指代，完成后更新未译单元和未解问题。
续批继承已确认且适用的译名，合并后检查衔接、注号和重复内容。
区分已译与已复校，不用排版页数代替内容完成率。
现在开始第一批。
```

之后可以说：

```text
继续。请先读取项目状态、覆盖记录和上一批末段，
沿用适用的术语决定，完成后续单元并更新进度。
```

交付重点：本批译文、更新后的进度、少量必要的疑点与修订。

## 7. 生成 Word 或 PDF

```text
请使用 $catholic-text-translation，把已经复校的译稿整理为【Word／PDF】。

当前译稿：【提供版本】
标题层级：【要求或沿用原稿】
字体字号：【指定要求】
目录与注释：【指定要求】

请使用环境中可用的文档工具，保留全部正文、注释及来源关系。
导出后查看渲染页面，检查漏段、截断、乱码、溢出、目录页码与内链。
说明实际完成的排版检查；无法执行的检查如实说明。
如果仅调整格式，不把这次操作称为新的语义复校。
```

这需要宿主环境具备相应文档工具。仓库本身不包含 OCR、Word 或 PDF 生成引擎。

## 让任务更容易完成的四项信息

1. **原文与定位**：提供实际可读取的材料，尽量保留邻文和原注。
2. **明确范围**：哪几章、哪些附录和注释；不要只说“全部”。
3. **已有决定**：术语表、已译稿及此前修订，帮助保持一致。
4. **输出要求**：简繁、文风、单语／对照和文件格式。

不知道的项目可以注明未知，由助手先作可支持的判断；无法核实的部分仍应保留不确定性。
