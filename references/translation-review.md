# 句法复核与纠错

用于全卷复校、核心定义或已报告误译；普通短句不必建立额外报告。以下案例用于识别故障，不是适用于所有作者与时代的替换词典。

## 两轮检查各自解决什么

原文对照以实际纳入的每个单元为范围，检查主语、谓语、直接对象、修饰归属、并列层次、条件与否定。核心定义先用简短中文列出它实际限定的主体、行为、对象和条件，再与重译后的句子核对；若任何限定无法落实，继续解析或保留局部歧义。参考译本用来对照，不取代原语言判断。

中文通读暂时离开原文，检查读者能否辨明谁做什么、什么修饰什么，是否有属格堆叠、错误搭配、悬空从句、被动句生硬或润色后重复词。特别检查词语拼接形成的异常搭配和使字结构中缺失的主语。异常中文只是回查信号，不凭现代教义常识直接改写史料。拆句后再回看原文，防止条件只约束了其中一句或否定丢失。

现成中文译本不免于上述检查。指代、关系从句或节引边界冲突时，以实际原文及必要见证核验；参照本的删节、注号重编或表达惯例不是试译的自动评分标准。具体首轮例子及测评方法见 [人工译本对照测评与风险表](benchmark-and-risk-cases.md)。

## 已发生错误的核验案例

| 原词或结构 | 应识别的关系 | 易错结果与改法 |
|---|---|---|
| divinus Redemptor；ea infallibilitate pollere | 前者是“神圣救主”；后者的享有对象是不可错误性 | 不生成“具有天主的救赎者”。修整整个定义段，保留职务、权威、信仰或道德对象、定义行为及全教会范围 |
| Filius Dei vivi | vivi 修饰 Dei | “生活天主之子”，不能误接成“天主的生活之子” |
| damnamus illorum sententias | 谴责的对象是那些人的意见 | 不缩写成“我们谴责那些人”；关系从句继续说明意见的内容 |
| 两个并列否定，其中一个含“只是” | 先确定每个否定分别排除什么 | 不将“既不只是……也不是……”改为逻辑不同的“不仅……也不……” |
| 赋予某定义另一意义 | 区分改变意义与替换定义本身 | 不把“给定义赋予另一意义”译成“以意义取代定义” |
| 世俗权力、平信徒及敬礼动作 | 结合所论主体、制度与对象判断 | 政教关系中的词不自动译为平信徒；钦崇与敬奉的术语更正也不能机械覆盖所有上下文 |

前三项可核对[《永恒牧者》拉丁文](https://www.vatican.va/archive/hist_councils/i-vatican-council/documents/vat-i_const_18700718_pastor-aeternus_la.html)：第四章最终定义、第一章伯多禄宣信引语、第三章关于联系自由的段落。网页其他位置可能有转录问题，仍须比较可靠见证；案例中的修订中文是自译，不冒称官方中文译文。其余行是本项目故障类型的概括，不是逐字引文或独立历史论证。

## 用户纠错后的处理

1. 找到截图或引文所在的原文及当前译文，核验整个句子与必要邻段；区别真实误译、可接受异译和纯中文润色。用户建议是核查线索，已证实才纳入修订。
2. 对真实错误说明影响：修饰归属、直接对象、否定或条件、术语、文献身份等。修订与此结构相关的全文段落、译注和摘要，不只改截图词语。
3. 按实际故障选择追查范围：核心定义或系统性结构问题需复核相关章节乃至全卷；孤立排版错字不自动触发全书重新翻译。检索同词帮助定位，仍须逐处按语境判断。
4. 记录位置、改前、改后及依据。将意义与限定、术语、语序润色、来源修正和排版问题分开；操作数、涉及段落数与独立误译数不互相替代。
5. 成稿重新通读改动邻段，检查是否引入重复词或新的歧义；生成当前交付版本后，再核对实际输出文字。保留前版与未解项。

## 不混同四种检查结果

- 来源核验：原文实际可见、所用见证及版本问题；未独立查过的转引卷页仍保持该身份。
- 覆盖审计：所选范围每个单元有去向；不证明句意正确，也不证明档案全集已收齐。
- 语义与语言复核：实际比对及通读过的范围；不能以书签、字数或脚本通过代替。
- 输出排版核验：PDF或Word有无漏段、截断、乱码、目录错页及坏链接；字号改变后要更新当前版本定位。

报告实际完成的层次与局部限制，不宣称“所有错误已彻底清除”。本规则的作用是增加可检查的复核步骤，而非保证译文绝对无误。

## 分级诊断与修复闭环

按错误的实际后果分级，短篇不用额外评分表：

- **关键错误**：改变核心命题、否定/条件、位格与本性、钦崇对象，或把草案冒作正式定义。明确修复并回查来源及关联位置；未解时局部标识，不把该版本称为已完整复校的定稿。
- **一般误译**：漏译、添义、指代或术语不符，但未达到上述核心后果。先修意义，再润色；同一故障不因多轮检查而重复计数。
- **表达/排版问题**：意思可成立，中文生硬、标点或换页有问题。调整后仍检查是否意外改变了语义；纯风格偏好与可接受异译另外说明。

将源文本身的残缺、异文和未明指代记为来源问题，不计作已证明的译文错误。每项记录来源ID、类别、证据、修订及复查状态，优先解决意义问题。若反复改写仍不能确定，停止该处盲改，查针对性见证或明确未解，继续其余部分；不以预设固定轮数、自动评分或“零错误”口号作完成保证。

保留有用的原稿和修订依据，交付稿清理工作标记。用户看到的结果应是中文译文及必要说明，而非强制附带每轮直译、回译或多语言对照。自查、人工复核、独立复核与脚本检查分别按实际情况标识，不能把同一助手的再次阅读冒称独立人工校对。
