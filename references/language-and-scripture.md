# 术语、拉丁句法与圣经引文

## 术语的使用原则

下表是中文天主教翻译的候选译法与风险提示，不是跨时代替换词典。以作者实际用法、文类、历史语境及用户指定译名为准。必要时首见作短译注，不把全篇变成词源研究。已确认的决定形成项目术语表。

| 原词／概念 | 候选译法 | 需要检查的区别 |
|---|---|---|
| Deus；Spiritus Sanctus；apostolus | 天主；圣神；宗徒 | 普通灵、使者等语境另判；人名书名采用适用的天主教习惯 |
| fides；spes；caritas | 信德；望德；爱德 | 非神学德性语境可分别为信仰／信念、希望、爱等 |
| gratia；iustificatio | 恩宠；成义 | 一般恩惠、法律正当化等不能机械套用 |
| gratia actualis／sanctificans | 现时恩宠（宠佑）／圣化恩宠 | 常居、惯常、圣化等词间关系依作者判断；现代教理只校准译名 |
| substantia／essentia／natura | 实体／本质／本性 | 不任意互换；古代和经院语境可能不同 |
| persona／hypostasis／suppositum | 位格／自立体等 | 先区分原词、时代、人格与非人格主体，不建立无例外的一一对应 |
| actus／potentia；esse | 现实（或实现）／潜能；存在等 | actus也可为行为；esse的技术含义按论证校准 |
| causa formalis；transsubstantiatio | 形式因；实体转变 | 不能缩成一般原因或只指外观变化 |
| primatus；iurisdictio | 首席权；管辖权 | 首位、荣誉、治理与法律权限分开 |
| potestas ordinaria；magisterium ordinarium et universale | 通常权力；普通且普世训导 | ordinaria不表示权力强弱；这两个语境不混同 |
| infallibilitas；irreformabilis；ex cathedra | 不可错误性；不可更改；从宗座发言 | 保留主体、行为、对象与条件，不改成所有言论无误 |
| societas perfecta | 完备团体（依语境） | 技术上的自足及目的所需手段，不是成员无道德缺陷 |
| sacramentum；ordo；reliquiae | 圣事；圣秩；圣髑 | ordo也可为秩序等；历史圣事名称及纪律不静默现代化 |

### 敬礼等级与动作

本项目确认的中文习惯：latria为**钦崇礼**，用于天主；hyperdulia为**超敬礼**，用于圣母；dulia为**敬礼**，用于圣人、天使。词的实际句义仍按所译文本判断。

- 对天主或基督的adoratio／adoremus，涉及钦崇时采用“钦崇”；相关译注同步。
- cultus、veneratio、colere、honor等可指敬礼、敬奉、尊敬或其他动作，不一概改成“钦崇”。特别留意否定理由、圣像所指向的原型，以及转引反对意见中的发言层次。
- 不把文本未作出的三分法补入正文；不能仅因出现一个拉丁词就对整段作现代训导分类。

### 谴责、法律与礼仪

anathema sit等历史公式按文类准确处理；本项目可采用“则应受绝罚”，但不能自动等同现代法典的具体处罚机制，亦不对某人的责任作推断。草案中的公式仍是拟议文字。

法律、信理、纪律及礼规保留区别：禁止不等于无效；应接受某教导不等于已有具体个人处罚。历史“终傅”等名称可以保留，现代名称只作必要译注，不能改写当时制度。

## 拉丁文复校的高风险位置

先确定谁说、对谁说、判断或规定什么，再核对修饰和从属关系。尤其检查：

- 主格与宾格、形容词与其名词的性数格配合、属格层级、代词先行词、被动施事者；长句主语是否中途被误换。尤其避免把天主的属性误接到“子”、动作或人名上。
- non、ne、nisi、tantum、solum及其作用范围；条件句、例外和双重否定。“不只是”不等于“不”，两个并列否定不能随意改成“不仅……也不……”。
- et／aut／vel及并列层次；目的句、结果句、间接陈述、分词、独立夺格、虚拟式及义务表达。
- “我们定义”等发言属于作者结论、异议、引述、答复还是预拟文本。
- “本身”“由于”“仅在”“全教会”等限定；实然、应然、可能、必要不能互换。
- 谴责、禁止、赋予或更改的直接对象是命题、意见、行为还是人；检查宾语和关系从句，不能把“某人的意见”缩成“某人”。
- potestas laica 等词按教会内职分或政教关系语境判断，区分平信徒与世俗权力；技术词依其句境定译。

查英文前先形成原文句法判断；译本冲突时查原词及可靠见证，不以英文更顺为裁决。中文可拆句，但保持逻辑连接和适用范围。直译难以自然表达时，可通顺改写；增加解释必须标为译注，不伪装原句。

对需要重整整句或已发现错误的段落，另按 [句法复核与纠错](translation-review.md) 检查；单词检索不能代替段落复核。

## 圣经引文处理

逐项记录来源位置、实际引语、原注经节、核定定位、所用中文版本、引文／节引／意译／典故、异文和处理。只有原文确实引到的内容才译入引号，不用完整经节扩写片段。

1. 先按实际文字识别经节，再核对原注；原注错了留更正说明，不默默复制错误。
2. 查可实际读取的思高中文经文或用户指定版本，核对书名、节号、引文边界和用语。未读正文不声称已核验。
3. 内容一致时采用相符的中文措辞；原文是转述时保持转述，不伪装逐字引文。
4. 武加大、古拉丁、七十贤士及现代版本存在实质差异时，优先忠于文献所引文字，必要时自译并注“据所引原文译”；不能把它冒称思高本逐字引文。
5. 古今编号不同，尤其《圣咏》、部分旧约及古版新约节号，提供核实的对应；不猜编号。借助邻句定位，并保留原文编号的版本身份。

中文教理、礼书和现成天主教译文可作译名参照，其官方性或适用范围须核实；后出的术语辅助不证明早期作者已有同样的精确定式。公共在线经文站是读取渠道，不自动等于译本出版机构。

现成会议中文译本的经文节引也须回查：它可能缩短了原语引文或经节范围。不要把该删节继承进自译，也不要为了恢复范围而补入原文未引的整节。已读思高经文后，另核对修改稿仍只覆盖实际引语；原注标某语言不等于助手已经直接读取该语言底本。
